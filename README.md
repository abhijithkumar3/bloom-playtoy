# BLOOM — Living Botanical Canvas

A full-screen interactive botanical canvas where clicks grow luminous plants and cursor movement becomes wind.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
