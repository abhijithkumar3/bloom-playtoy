# BLOOM 🌱

### An Interactive Generative Botanical Experience

BLOOM is a small interactive visual experience created for the **Dodo Payments Design Engineer Assignment**.

The experience transforms a simple interaction into a living botanical world:

* 🖱️ **Click anywhere** to grow a unique flower.
* 🌱 Watch the plant develop from **root → stem → branches → leaves → bloom**.
* 💨 Move the cursor around the plants and create **wind**, making them sway naturally.
* ☀️🌙 Experience an automatic **day-to-night cycle** as the environment evolves.
* 🌿 Create multiple plants and gradually build your own generative garden.

The project focuses on **interaction, visual craft, generative graphics, animation, and frontend engineering**.

---

## ✨ Core Interaction

**CLICK → GROW → MOVE → WIND → WATCH**

Every plant is procedurally generated with variations in its:

* Stem
* Branches
* Leaves
* Flower shape
* Size
* Growth behavior
* Position

The cursor acts as an invisible wind source, allowing the plants to react naturally to movement.
